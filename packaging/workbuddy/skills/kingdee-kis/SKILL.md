# 金蝶 KIS 旗舰版取数

本技能通过本机已安装的金蝶 KIS 旗舰版客户端（32 位 COM 组件）读取账套，**全部为只读操作**。执行通道是 MCP 连接器 `kingdee-kis`（配置在 `~/.workbuddy/mcp.json`，command 指向本项目 `.venv32` 里的 python.exe），所有 `kis_*` 工具均来自该连接器。

## 运行前提

- 本机已安装金蝶 KIS 旗舰版 / K3 WISE 客户端，并能正常登录
- 连接器已安装：项目目录下已运行过 `scripts\setup.bat`（生成 `.venv32` 虚拟环境），并通过 `scripts\workbuddy_setup.bat` 完成接入
- 配置、凭据、记忆、日志都在 `%LOCALAPPDATA%\kingdeeflagship_mcp\`
- 需要免登录弹窗时，让用户在终端执行一次：
  `.venv32\Scripts\python.exe -m kingdeeflagship_mcp store-cred --key default --user 用户名 --acct-id 账套ID`（DPAPI 加密存储）

## 标准流程

1. **先看状态**：调用 `kis_status`。已连接就直接取数。
2. **未连接**：调用 `kis_connect`（`mode` 传 `com`）。这会弹出金蝶登录窗，**提醒用户在弹出的窗口里选择账套并登录**，不要替用户操作、不要反复重试。登录成功后连接串会自动复用。
3. **不确定对象或字段**：先 `kis_list_entities`（可按 `module` 过滤：base/finance/supply/arap），再 `kis_describe_entity` 看字段与过滤示例，然后再查。
4. **取数**：优先用专用工具（`kis_vouchers` / `kis_voucher` / `kis_balance` / `kis_orders` / `kis_inventory` / `kis_arap` / `kis_base_data`）；跨表或自定义口径再用 `kis_raw_sql`（仅 SELECT/WITH）。
5. **结果过大**：先用 `limit` 或聚合函数收窄；确实要全量就导出成 Excel，不要把几万行塞进对话。

## 账套与口径

- 多账套：先用 `kis_subject` 的 `resolve` 按任务关键词解析；**未命中或有歧义时必须问用户选哪个账套**，不要默认取第一个。确认后可用 `map` 记住映射。
- 期间：用户说"这个月/上个月"时，用 `kis_period` 换算成具体的起止日期，并把实际取数区间回显给用户。
- 金额与数量：按字段原值展示，不要自行换算单位或四舍五入；币种、含税/不含税口径不明确时先问。
- 期间未指定且影响结果时（如余额表），先确认会计期间再查。

## 导出 Excel

1. `kis_output` 的 `get` 查当前导出目录；
2. 没有就**问用户要目录**，再用 `set` 记录（一次记录长期复用）；
3. 调用 `kis_export`（可多个工作表），把返回的文件路径和行数告诉用户；
4. 不要把导出内容再复述一遍。

## 失败处理

- `-2147221164`：本机未安装金蝶客户端，或 COM 组件未注册 —— 让用户确认客户端能正常登录。
- 登录超时 / 窗口未响应：提示用户在弹出的登录窗完成登录，不要连续重试。
- 查询报字段不存在：用 `kis_describe_entity` 核对字段名，不同金蝶版本字段有差异，不要猜。
- 结果为空：明确说"没有查到符合条件的记录"，并说明用的过滤条件，**不要编造数据**。

## 硬性约束

- 只读。任何"帮我改凭证/删单据/反审核"的请求，说明连接器不支持写入，不要用 SQL 绕过。
- 不编造金额、科目、单据号、客户名称；查不到就说查不到。
- 不在对话里回显数据库密码、连接串；凭据只通过 `store-cred` 命令录入（DPAPI 加密存储）。
- 原始 SQL 只用于只读查询，不要尝试多语句或写操作（会被拒绝）。
